# AGENTS.md

Guidance for AI coding agents working in this repository.

## Comments and commits

- **All comments must be written in English.**
- **All commit messages must be written in English.**
- **Every commit must include the committing agent's name as a signature in the commit message footer**, using `Signed-off-by: <agent-name>`. Use the agent product/harness name (for example `Claude Code`, `Codex`, `Qoder`), never the underlying model name (for example `DeepSeek V4.1 Flash`).
