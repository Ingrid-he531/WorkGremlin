# 办公室页面
## 测试条目（以上每个楼层均适用）

1. 主 agent 相位变化：思考中、调用工具、等待授权、任务完成/任务取消
2. 楼层监控滚动条，任务滚动和任务完成/取消状态
3. 在AI任务进行中重启应用，测试条目 #1、#2
4. 召唤小怪物：小怪物与主 agent 互动，小幽灵出现；小怪物的忙状态与任务查看；任务结束或取消时，小幽灵自动消失
5. 召唤临时小怪物：小幽灵出现；任务结束或取消时，小幽灵消失
